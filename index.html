Project Title : computer vision application : vehicle counting classification system from real time videos

This is a computer vision-based application developed as part of an academic group project, completed by a team of three members. The objective of the project was to detect and count moving vehicles in a video stream using image processing and object tracking techniques.The system was implemented using Python and OpenCV, and it utilizes background subtraction and contour detection for real-time vehicle counting.

🚦 problem statement :

numerous challenges that exist within urban transportation and traffic management.these systems offer critical issues that are need to be addresed.

  • Inadequate traffic data
  • Traffic congestion
  • Road safety

🎯 applications :

Traffic management and Optimisation, Road safety and accident prevention, Parking management

🔍 Existing system :

  • ROI selection
  • detection of moving objects
  • clustering process
  • tracking
  • single frame classification and counting

    • 🚀 proposed system :

    the proposed system contains yolo-v3 model(you only look once)

    • stage 1 : aquire video as input
    • stage 2 : background subtraction, moving object from background
    • stage 3 : use YOLO (You Only Look Once) a deep learning algorithm. locates objects in real time video frames.
    • stage 4 : further analyze and classify the objects using darknet framework.darknet is a neural network framework well suited for classification tasks.classifies vehicles into different categories such as cars, trucks, motorcycles, or any other relevant classes.
    • stage 5 : count and analyze the detected and classified vehicles.
    • stage 6 : finally, the system provides the video output with the processed information on the screen video feed.

    📈 Outcome :

    Our system achieved over 90% accuracy in vehicle detection and classification across multiple test videos, demonstrating its potential for real-world deployment in traffic monitoring systems
